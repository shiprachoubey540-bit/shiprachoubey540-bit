### 🚀 Featured Projects

**[Skin Lesion Classification (SVM)](https://github.com/shiprachoubey540-bit/Skin-Lesion-Type-Classification-Using-Texture-and-Color-Features-with-SVM)**
Classifies skin lesions using GLCM texture features, HSV color histograms, and ABCD-inspired shape descriptors on the HAM10000 dataset. Handles class imbalance with SMOTE.

**[B2B Late Payment Predictor](https://github.com/shiprachoubey540-bit/B2B-Invoice-payment-behaviour-segmentation-late-payment-predictor)**
Predicts late B2B invoice payments using XGBoost with SHAP explainability, and segments customers by payment behavior via K-Means clustering. Includes full EDA and 30+ engineered features.

**[AI Financial Agent for Market Insights](https://github.com/shiprachoubey540-bit/AI-Financial-Agent-for-Real-Time-Market-Insights)**
An AI-powered agent delivering real-time market insights for the Zomato IPO, using NLP sentiment analysis across tweets, reviews, and YouTube comments.
